# Personal Portfolio Website

Personal portfolio website untuk menampilkan profil, skills, pengalaman, dan project yang saya kerjakan sebagai **Information Technology Graduate** yang memiliki minat pada **Web Development, Networking, dan Cybersecurity**.

## Features

* Responsive design
* Personal profile
* Skills & technologies
* Project showcase
* Contact section
* Modern and simple UI

## Tech Stack

* HTML
* CSS
* JavaScript
* React.js
* Git & GitHub

## Getting Started

Clone repository:

```bash
git clone https://github.com/MuhamadBunan/web-portfoliodari.git
```

Masuk ke folder project:

```bash
cd web-portfoliodari
```

Install dependencies:

```bash
npm install
```

Jalankan project:

```bash
npm run dev
```

Kemudian buka alamat localhost yang ditampilkan oleh terminal.
